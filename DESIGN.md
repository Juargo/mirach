# Design System: Tecno-Analítico (Dark Mode)

## Overview
**Creative North Star: "Precisión de Terminal"**
Un dashboard financiero oscuro, denso y estructurado. La aplicación se comporta como un instrumento de alta precisión.

**Key Characteristics:**
- Fondo oscuro mate (`#090A0F`), tarjetas ligeramente más claras (`#11131A`), sin sombras (`shadow-none`).
- Contraste funcional: el color se usa exclusivamente para estados semánticos (verde terminal para ingresos, rojo carmesí para egresos, cyan eléctrico para acentos).
- Tipografía dual: Inter (sans-serif) para lectura y etiquetas, y Geist Mono / JetBrains Mono (o tabular-nums) obligatoria para TODAS las cifras, fechas y montos.
- Bordes de 1px nítidos (`#1E222D`) en lugar de contenedores flotantes.
- Radios de esquina: cuadrados o mínimos (`--radius: 0` o `2px`).
